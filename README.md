# MAFIA BROTHERS

Mumbai-inspired open-city action-driving game for phones (landscape, touch).
Three friends – Veer, Bunty and Chintu – drive and walk around an original Mumbai-like city, shoot it out with a rival gang (arcade, no gore) and race a supercar and a hyperbike.

Developer: Aditya Solanki

## v2 features
- On-foot mode: EXIT / ENTER button, joystick, third-person character, drag the right side to look.
- Guns: SHOOT with auto-aim, pistol / SMG / shotgun, weapon pickups, health + ammo HUD. Enemies tip over and vanish – no blood.
- Wanted level (police) if you shoot traffic or crash hard in free roam; BUSTED meter.
- Toro V12 supercar and Hyper H-Blade hyperbike (lean handling) parked at the Mafia Garage; selectable in free roam from the pause menu.
- New missions: Maidan ka Muqabla (gang shootout), Toro Escape (police escape), Hyper H-Blade Run (bike race).
- Camera no longer clips through buildings.

All graphics are procedural (Three.js r169, bundled locally) and all sounds are synthesized with WebAudio. No third-party game assets, no real brands or logos.
